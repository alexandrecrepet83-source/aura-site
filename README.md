# Aura — L'entretien intelligent

Site vitrine conceptuel pour Aura, un pot connecté qui surveille et entretient les plantes d'intérieur.

Sections : présentation, fonctionnement animé, anatomie du pot, simulateur de plante, application, bibliothèque de plantes, mode vacances, comparatif, pré-commande et FAQ.

## Lancer en local

```bash
python3 -m http.server 8000
```

Puis ouvrir http://localhost:8000.

Projet conceptuel : visuels générés par IA, caractéristiques et prix fictifs.
